# Requerimientos normalizados

CONTROL360 no es un sistema contable tradicional. Es un centro privado de control patrimonial para responder preguntas de inversión, compromiso, desembolso, recuperación, utilidad, ROI, punto de equilibrio, socios, riesgo y evolución de proyectos.

## Dominios principales

- Eventos.
- Negocios.
- Inversiones.
- Compras o adquisición de empresas.
- Proyectos digitales.
- Inmuebles.
- Activos.
- Oportunidades.
- Patrimonio personal.
- Socios y participaciones.
- Ingresos, gastos y desembolsos.
- Informes.
- Documentos.
- Proveedores, cotizaciones y compras.
- Usuarios invitados con permisos por proyecto.

## Alcance implementado en Fase 1

La primera fase entrega una base navegable y conectable:

- Dashboard general con datos demo.
- CRUD visual de proyectos con almacenamiento local si no hay backend.
- Detalle básico de proyecto.
- Registro visual de ingresos y gastos.
- Catálogo inicial de gastos.
- Vista visual de socios.
- Apps Script con estructura de API y hojas mínimas.
- Documentación de despliegue y seguridad.

## Alcance diferido

Se deja preparado, pero no completo en Fase 1:

- Autenticación real e invitaciones.
- Confirmación de correo.
- Permisos por proyecto.
- Carga de archivos a Drive.
- Envío real de correos.
- Informes PDF finales.
- Restauración de versiones.
- Automatizaciones de alertas.
