# Identidad visual de CONTROL360

## Direccion

CONTROL360 debe verse como una plataforma privada, empresarial y tecnologica: ERP inteligente, finanzas, analisis de datos, patrimonio, automatizacion e innovacion.

La marca mantiene una base oscura con cristal, brillo LED, profundidad 3D, reflejos metalicos y glow verde neon/lima.

## Tipografia

La tipografia principal de marca es ACCESS de designova. Debe aplicarse en:

- Logotipo y wordmark CONTROL360.
- Titulos y encabezados.
- Botones principales.
- Navegacion.
- Tarjetas, modulos y KPIs destacados.
- Material grafico de marca.

El frontend ya incluye `@font-face` apuntando a:

- `frontend/assets/fonts/ACCESS.woff2`
- `frontend/assets/fonts/ACCESS.woff`
- `frontend/assets/fonts/ACCESS.ttf`

Para produccion se debe colocar ahi el archivo licenciado. No se debe subir una fuente sin licencia valida.

## Logo

El asset activo del logo esta en:

`frontend/assets/brand/control360-logo.png`

La palabra CONTROL360 debe seguir siendo el elemento principal de la marca. El emblema puede usarse como sello o marca secundaria en sidebar, login y piezas graficas.

## Paleta

Mantener la paleta actual aprobada:

- Fondo oscuro premium.
- Verde neon/lima como luz principal.
- Cristal/transparencias en paneles.
- Reflejos metalicos claros.
- Glow tecnologico sin volver a una identidad azul/morada dominante.
